# Ginseng ecological suitability analysis code

本仓库整理了 *Panax ginseng* 生态适宜性、环境驱动、未来气候情景、预测不确定性和长期种植候选区研究的分析脚本。它是原始工作目录 `E:\人参种在哪` 的**代码快照**，保留了原来的中文目录名和脚本顺序，便于与论文方法和结果核对。

## 仓库结构

| 目录 | 内容 |
| --- | --- |
| `00_统一数据预处理/scripts/` | 原始数据清点、标准化、栅格对齐及质量检查 |
| `实验1/scripts/` | 当前适宜性建模与空间交叉验证 |
| `实验2/scripts/` | 环境驱动、SHAP、ALE 和阈值分析 |
| `实验3/scripts/` | 气候、土壤、地形贡献分析 |
| `实验4/scripts/` | 未来气候预测与适宜性变化 |
| `实验5/scripts/` | 不确定性、环境新颖度及脆弱性 |
| `实验6/scripts/` | 早期种植候选区分析，保留供方法追溯 |
| `实验6B/scripts/` | 修订后的种植候选区分析与绘图 |
| `Supplementary_Validation/` | 对统计域、筛选掩膜、AUC 和阈值的补充验证 |
| `绘图/` | 论文主图的数据准备与溯源脚本 |

## 环境与运行

原始运行环境为 Windows、Python 3.11.15。主要依赖记录在 [`requirements.txt`](requirements.txt)；MaxEnt 和部分旧版 GAM 脚本还分别使用 `elapid`、`pygam`。这些可选包未出现在保存的环境快照中，运行相应脚本前需单独确认版本和安装情况。

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
```

脚本以分阶段目录为工作空间，通过上游阶段的交接文件读取输入。运行顺序与各阶段的预期输入见 [`REPRODUCIBILITY.md`](REPRODUCIBILITY.md)。`实验6` 是较早的分析版本；修订后的候选区分析位于 `实验6B`，对应的审计代码位于 `Supplementary_Validation/`。

**路径要求：** 原脚本大多将工作目录写为 `E:\人参种在哪`，且实验1的 YAML 配置也包含该路径。若在另一台机器运行，需将脚本与配置中的绝对路径改为本机工作目录，并保持相同的阶段目录及交接文件结构。`00_统一数据预处理/scripts/07_process_future_climate.py` 中唯一包含原 Windows 账户名的路径已改为当前用户主目录，其余分析逻辑未改动。当前仓库尚未提供跨平台的一键运行入口。

## 数据范围与复现边界

本仓库只上传脚本、少量配置和简明运行说明。原始下载数据、GeoTIFF/GeoPackage、模型文件、阶段交接包、生成的图表、文献 PDF 和本地日志均未上传。它们在原工作目录中占用数十 GB，并可能受到各数据源许可约束。仅克隆本仓库不能重算论文结果；复现还需要取得原始数据，并构建各阶段输入。具体数据来源及文件含义应以论文的数据可得性说明和原始数据源为准。

补充验证发现早期实验6的部分统计与修订后的实验6B存在差异。因此引用候选区数字前，应核对修订脚本和论文最终文本。
